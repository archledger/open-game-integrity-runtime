# Licensing map

The repository is intentionally multi-licensed by component.

| Path or component | License |
|---|---|
| Rust core, verifier, SDK, documentation, and attack lab | Apache-2.0 |
| Code prepared for upstream inclusion in Wine | LGPL-2.1-or-later |
| BPF-LSM and Linux-kernel-facing program source | GPL-2.0-only unless upstream requirements demand another compatible identifier |

Every source file must contain an SPDX identifier. Do not copy implementation code across license boundaries without a documented license review.

The OGIR name, logo, and future certification marks are not granted by the software licenses. A separate trademark policy will be created before certification claims are permitted.
