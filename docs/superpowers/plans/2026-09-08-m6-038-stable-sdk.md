## Development notes

- unique_ptr with a custom deleter fights hand-written move
  constructors: for two tiny owner classes a raw pointer +
  explicit close/move is clearer and compiles cleaner.
- The fuzz crate needs [workspace] in ITS Cargo.toml to escape the
  main workspace; gitignore corpus/artifacts/target/lock.
- service_route fuzzing needs a real TcpStream pair (the HTTP
  layer reads from streams): listener+connect+write+drop per run
  is cheap enough at these run counts.
- A fuzz target that rejects all inputs still reports DONE with
  corp 1/1b - that is success, not starvation.
