## Development notes

- Replacing an enum with a struct ripples into every test
  construction: update the FixedProcessor test impl FIRST to find
  all use sites mechanically.
- Module-internal test code cannot use crate-qualified paths
  (ogir_verifier::...) - plain names resolve.
- Arc<DevBackend> across threads: bind `let backend: &DevBackend =
  backend.as_ref();` once per closure; `&Arc` does not coerce to
  multiple &dyn Trait slots simultaneously.
- A threaded test server must serve EXACTLY the connections the
  test makes (a missing slot = client ConnectionRefused panic,
  not a logic failure).
- renewal nonce reuse of appraised_nonce keeps the renewal
  challenge deterministic for tests.
