## Development notes

- Mainline wine 11.17 does NOT attach a unixlib to an app-dir
  native PE (native-first skips the builtin phase); the working
  per-prefix recipe: PE in the WINEPREFIX's
  drive_c/windows/system32 + .so in the installation's
  x86_64-unix. Under Proton: .so in the Proton build's
  files/lib/wine/x86_64-unix, PE in the STEAM_COMPAT_DATA_PATH
  pfx system32, run via `proton run` with
  STEAM_COMPAT_CLIENT_INSTALL_PATH set.
- Proton's run wrapper swallows the child's stdout: the harness's
  exit code IS its failure count (0 = all green) - use exit codes
  plus the portal log as the verdict, not the console.
- rsplit_once returns a TUPLE; binding the tuple's fields
  explicitly avoids the method-on-tuple compile error.
- The first `proton run` creates/upgrades the prefix (a busy run
  with no test output); the second run executes the test.
- Wine refuses prefixes under /tmp; use home-path prefixes.
- Long ssh one-liners with heavy quoting break: put the runner in
  a script file, scp it, execute it.
