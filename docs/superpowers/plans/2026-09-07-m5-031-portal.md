## Development notes

- std::os::fd::AsRawFd must be imported for as_raw_fd; edition-2024
  requires `unsafe extern "C"`; the extern declaration itself trips
  the unsafe lint, so it lives INSIDE the single allow-annotated
  function (one allow attribute total, as the gate counts).
- sun_path is 108 bytes: cargo's deep worktree tmpdir overflows it;
  tests bind short /tmp paths.
- The first draft chmod'd the socket's parent directory
  unconditionally - binding in /tmp then attempted chmod("/tmp")
  and failed EPERM. The portal must only harden directories IT
  CREATES; never re-permission a pre-existing shared directory.
- Single-threaded serve tests deadlock if the client waits for
  responses the server has not yet written: shutdown(Write) before
  serving, or a server thread for the live-interaction flood test.
- A test helper returning `&'static str` from borrowed bytes breaks
  lifetimes; rejection reasons are static on the wire, so the test
  asserts the raw frame bytes.
